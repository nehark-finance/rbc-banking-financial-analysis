# Workbook Guide

| Sheet | Purpose |
|---|---|
| `01_Cover` | Project title, scope, author, and navigation |
| `02_Project_Charter` | Project objective, business questions, assumptions, and status |
| `03_Source_Register` | Source-document inventory and traceability |
| `04_Definitions` | Banking and financial KPI definitions |
| `05_Raw_Annual_Performance` | Annual reported performance data |
| `06_Raw_Quarterly_Performance` | Quarterly data from Q1 2024 through Q2 2026 |
| `07_Raw_Balance_Sheet` | Balance-sheet, asset, deposit, equity, and loan data |
| `08_Raw_Credit_Quality` | PCL, ACL, impaired-loan, and write-off information |
| `09_Raw_Capital_Liquidity` | CET1, total capital, RWA, LCR, and NSFR data |
| `10_Raw_Segment_Results` | Revenue and earnings by business segment |
| `11_STD_Performance` | Standardized annual performance schedule |
| `12_STD_Balance_Sheet` | Standardized balance-sheet schedule |
| `13_STD_Credit_Risk` | Standardized credit-risk schedule |
| `14_STD_Capital_Liquidity` | Standardized capital and liquidity schedule |
| `15_KPI_Analysis` | Annual KPI calculations and trend analysis |
| `16_Quarterly_Trends` | Quarterly profitability and risk trends |
| `17_Segment_Analysis` | Comparative segment analysis |
| `18_Dashboard_Data` | Supporting data layer for the dashboard |
| `19_Dashboard` | Executive performance, credit-risk, and capital dashboard |
| `20_Analyst_Commentary` | Written financial commentary and conclusions |
| `21_Interactive_Analysis` | Interactive annual KPI and segment analysis |
| `22_Advanced_Excel` | Advanced formula showcase and segment ranking |
| `23_Pivot_Source` | Normalized long-format source table |
| `24_Pivot_Summary` | Formula-driven pivot-style summary |
| `25_Data_Audit` | Reconciliation and quality-control checks |
| `26_Native_PivotTable` | Native PivotTable with filters and slicers |

## Recommended Review Order

1. `01_Cover`

3. `19_Dashboard`
4. `20_Analyst_Commentary`
5. `21_Interactive_Analysis`
6. `22_Advanced_Excel`
