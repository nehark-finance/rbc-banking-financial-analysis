# Workbook Guide

| Sheet | Purpose |
|---|---|
| `01_Cover` | Project title, author, scope, and high-level navigation |
| `02_Project_Charter` | Objective, business questions, scope, assumptions, and project status |
| `03_Source_Register` | Source-document inventory and traceability |
| `04_Definitions` | Banking KPI definitions and interpretation |
| `05_Raw_Annual_Performance` | Reported annual income-statement and performance data |
| `06_Raw_Quarterly_Performance` | Quarterly performance data from Q1 2024 to Q2 2026 |
| `07_Raw_Balance_Sheet` | Balance-sheet and loan information |
| `08_Raw_Credit_Quality` | PCL, ACL, impaired loans, and write-off data |
| `09_Raw_Capital_Liquidity` | CET1, capital, RWA, LCR, and NSFR information |
| `10_Raw_Segment_Results` | Revenue, earnings, ROE, and efficiency data by business segment |
| `11_STD_Performance` | Standardized annual performance schedule |
| `12_STD_Balance_Sheet` | Standardized balance-sheet schedule |
| `13_STD_Credit_Risk` | Standardized credit-risk schedule |
| `14_STD_Capital_Liquidity` | Standardized capital and liquidity schedule |
| `15_KPI_Analysis` | Annual KPI calculations, trends, and interpretation |
| `16_Quarterly_Trends` | Quarterly trend analysis |
| `17_Segment_Analysis` | Comparative business-segment analysis |
| `18_Dashboard_Data` | Supporting calculation layer for the dashboard |
| `19_Dashboard` | Executive financial-performance and risk dashboard |
| `20_Analyst_Commentary` | Written financial analysis, strengths, risks, and conclusion |
| `21_Interactive_Analysis` | Dropdown-based annual KPI and segment-period analysis |
| `22_Advanced_Excel` | Advanced formula showcase and dynamic segment ranking |
| `23_Pivot_Source` | Normalized long-format source table for PivotTables |
| `24_Pivot_Summary` | Formula-driven pivot-style summary |
| `25_Data_Audit` | Reconciliation checks and data-quality review |
| `26_Native_PivotTable` | Native Excel PivotTable with interactive filters and slicers |

## Recommended Review Order

1. `01_Cover`
2. `02_Project_Charter`
3. `19_Dashboard`
4. `20_Analyst_Commentary`
5. `21_Interactive_Analysis`
6. `22_Advanced_Excel`
7. `26_Native_PivotTable`
8. `25_Data_Audit`

## Important Notes

- Blank cells may represent metrics that RBC did not separately disclose.
- These blanks should not be interpreted as zero.
- Amounts are in CAD millions unless otherwise stated.
- The interactive workbook works best in Microsoft Excel.
